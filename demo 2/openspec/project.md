# Проект: Автоцентр

## Назначение

Система предназначена для учета автомобилей в автоцентре.

Система позволяет:
- принимать новые автомобили;
- просматривать автомобили;
- редактировать информацию об автомобилях;
- продавать автомобили;
- удалять записи об автомобилях;
- формировать отчет о количестве автомобилей в наличии и количестве проданных автомобилей.

## Предметная область

Основной объект системы — автомобиль.

Для автомобиля хранится:
- марка;
- модель;
- год выпуска;
- VIN;
- цена;
- статус;
- дата добавления;
- дата продажи.

## Ограничение базы данных

Предметная область использует одну таблицу автомобилей.

Структура базы данных создается системой миграций Liquibase.

## API

Система предоставляет REST API для выполнения операций над автомобилями.

## Проверка

Работа API демонстрируется через Swagger UI / OpenAPI.
